# Sitio antiguo (archivo)

Todo lo que hay en esta carpeta es la web **anterior** a la migración a
Next.js: HTML estático, `script.js` y sus hojas de estilo. Se conserva solo
como referencia visual e histórica.

**Nada del build ni del seed lee estos archivos.** No los edites esperando
que cambie algo en la web.

Los datos que sí siguen vivos (los YAML que alimentan `npm run seed`) se
movieron a [`../supabase/seed-data/`](../supabase/seed-data/), que es donde
hay que tocarlos.
